# Economia Aplicada

Portfólio de modelagem em economia aplicada, com projetos acadêmicos
organizados por pasta. Cada pasta é um projeto independente, com README
próprio; os comandos de cada uma rodam a partir dela.

| Pasta | Conteúdo |
|---|---|
| [`Econometria/`](Econometria/README.md) | Econometria aplicada em R, Python, Julia e C (séries temporais, painel, finanças e avaliação de política) e modelos de equilíbrio geral em tempo contínuo sobre a tributação do capital no Brasil |
